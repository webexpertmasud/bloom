# Bloom & Co. Bootstrap 5 Flower Shop Template

## Included pages
- `index.html` — 14 homepage sections inspired by the supplied reference image, including four product collections
- `shop.html` — searchable, filterable product listing
- `product.html` — flower detail page
- `cart.html` — cart quantity controls, remove item, demo promo code `BLOOM10`
- `checkout.html` — Cash on Delivery form; prepares an order message for WhatsApp
- `tracking.html` — demo order list and status controls
- `contact.html` — contact form UI
- `account.html` — starter account page

## Run
Extract the ZIP and open `index.html` in a browser. An internet connection is needed for Bootstrap CDN, Google Fonts, Bootstrap Icons, and the externally hosted flower photos.

## Important
This is a front-end starter template. Cart and demo orders use browser `localStorage` and are not shared between devices or users. The WhatsApp checkout opens a prefilled message; the customer must send it. To launch a real store, connect a backend/database, configure the store WhatsApp number, email notifications, secure admin authentication, and production product images/data. Replace the example email and placeholder contact details.
